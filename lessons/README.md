# 🎓 حصص تفاعلية — دليل الإضافة

كل مادة/فصل لها ملفان في هذا المجلد، بنفس أسماء ملفات الألعاب:

```
lessons/
├── lesson.js          ← محرّك الحصص الموحّد (لا يُعدَّل)
├── _template.json     ← نموذج فارغ يوضّح كل الحقول
├── cs_s1.html         ← صفحة حاسوب الصف العاشر — الفصل الأول
├── cs_s1.json         ← حصص تلك المادة (هذا ما تعدّله)
└── ...
```

يصل الطالب إليها من الموقع: **الصف ← المادة ← 🎓 حصص تفاعلية ← الفصل الدراسي**.

---

## ✏️ إضافة الحصص

افتح ملف `JSON` الخاص بالمادة والفصل وأضف كل حصة كعنصر في `lessons`:

```json
{
  "book": "https://.../book.pdf",     ← (اختياري) رابط الكتاب المدرسي
  "plan": "https://.../plan.pdf",     ← (اختياري) رابط خطة التدريس
  "today": "L02",                      ← (اختياري) حصة اليوم الافتراضية
  "lessons": [ { ...حصة... }, { ...حصة... } ]
}
```

### حقول الحصة

| الحقل | الوصف |
|---|---|
| `id` | معرّف فريد (مثل `L01`) — يُستخدم لتحديد حصة اليوم |
| `date` | تاريخ الحصة `YYYY-MM-DD` — إن طابق تاريخ اليوم تُعرض تلقائياً كحصة اليوم |
| `unit` | اسم الوحدة |
| `title` | عنوان الحصة |
| `pages` | صفحات الكتاب (نص حر) |
| `duration` | مدة الحصة بالدقائق — تضبط المؤقّت (الافتراضي 45) |
| `objectives` | قائمة الأهداف |
| `vocab` | مفردات: `[{ "term": "...", "def": "..." }]` |
| `warmup` | أسئلة التمهيد — تُعرض واحدة تلو الأخرى |
| `content` | فقرات الشرح — كل فقرة شريحة مستقلة |
| `activity` | نشاط تفاعلي واحد (انظر الأنواع أدناه) |
| `check` | أسئلة تحقق من الفهم — كل سؤال شريحة |
| `summary` | نقاط الخلاصة |
| `homework` | نص الواجب |

كل الحقول اختيارية عدا `id` و `title` — الأجزاء الفارغة لا تظهر في الحصة.

### فقرة الشرح (`content[]`)
```json
{ "title": "...", "text": "...", "points": ["..."], "example": "...", "note": "...", "image": "img/x.png", "code": "..." }
```
داخل النصوص يمكن استخدام `**عريض**` و `` `كود` `` وسطر جديد `\n`.

### أنواع النشاط (`activity.type`)
- **match** — توصيل: `"pairs": [["المصطلح","التعريف"], ...]`
- **order** — ترتيب خطوات: `"items": ["الخطوة ١","الخطوة ٢", ...]` (بالترتيب الصحيح)
- **sort** — تصنيف: `"groups": [{ "name": "المجموعة", "items": ["..."] }, ...]`

### أسئلة التحقق (`check[]`)
- اختيار من متعدد: `{ "type":"mcq", "q":"...", "opts":[...], "ans":0, "exp":"..." }` — `ans` يبدأ من 0
- صح/خطأ: `{ "type":"tf", "q":"...", "ans":true, "exp":"..." }`

---

## 📅 كيف تُحدَّد «حصة اليوم»؟
بالترتيب:
1. حصة ثبّتها المعلم بزر **📌 تعيين لليوم** (تُحفظ في المتصفح نفسه).
2. حصة `date` يساوي تاريخ اليوم.
3. الحصة المذكورة في `"today"` داخل الملف.
4. أقرب حصة قادمة حسب التاريخ.

---

## 🎛 أثناء الحصة
- **← / →** أو **مسافة**: التنقل بين الشرائح · **F**: ملء الشاشة · **Esc**: العودة للقائمة
- **المؤقّت**: ضغطة = تشغيل/إيقاف · ضغطتان = إعادة · يتحوّل للأصفر عند ٥ دقائق وللأحمر عند دقيقة
- شريط المراحل أسفل الشاشة يسمح بالقفز لأي مرحلة.
