# 🤖 المساعد الذكي — دليل التشغيل

```
assistant.html        ← صفحة الدردشة (في جذر الموقع)
assistant/worker.js   ← الخادم الوسيط على Cloudflare (يحمل مفتاح Gemini ونص اللوائح)
assistant/README.md   ← هذا الملف
```

الموقع ثابت (GitHub Pages) فلا يمكن وضع مفتاح Gemini داخل الصفحة. لذلك تمر الأسئلة عبر **Cloudflare Worker** مجاني يحتفظ بالمفتاح ويرسل الطلب إلى Gemini ويعيد الجواب.

---

## ١. الحصول على مفتاح Gemini
1. افتح **aistudio.google.com** وسجّل الدخول بحساب Google.
2. **Get API key → Create API key** وانسخه.

## ٢. نشر الـ Worker (مرة واحدة)
1. أنشئ حساباً مجانياً على **dash.cloudflare.com**.
2. **Workers & Pages → Create → Create Worker** — سمّه مثلاً `falduwairi-assistant` ثم **Deploy**.
3. اضغط **Edit code**، احذف الكود الافتراضي والصق محتوى `assistant/worker.js` بالكامل، ثم **Deploy**.
4. **Settings → Variables and Secrets** وأضف:

| الاسم | النوع | القيمة |
|---|---|---|
| `GEMINI_API_KEY` | **Secret** | مفتاح Gemini |
| `MODEL` | Variable | `gemini-flash-latest` (أو أي نموذج آخر متاح في حسابك) |
| `ALLOWED_ORIGINS` | Variable | رابط الموقع بدون شرطة في النهاية، مثل `https://USERNAME.github.io` — افصل بين عدة روابط بفاصلة |

5. انسخ رابط الـ Worker من الأعلى (يشبه `https://falduwairi-assistant.USER.workers.dev`).

## ٣. ربط الصفحة
افتح `assistant.html` وضع الرابط في السطر:
```js
const API_URL = "https://falduwairi-assistant.USER.workers.dev";
```
ثم ارفع الملف. انتهى — افتح الموقع → 🤖 المساعد الذكي.

## قاعدة المعرفة المنظمة (صيغة الإجابة المزدوجة)
في أعلى `assistant/worker.js` المصفوفة `KNOWLEDGE` — مدخل لكل لائحة:

```js
{
  category: "الغياب والحضور",                 // التصنيف
  topic: "كلمات مفتاحية يغطيها هذا المدخل",     // يساعد المساعد على اختيار المدخل المناسب
  website_content: "الشرح المبسط للطالب",
  law_title_ar: "اسم اللائحة الرسمية",
  law_article_ar: "المادة 42",
  law_text_ar: "النص الحرفي من اللائحة",
  verified: false                               // true فقط بعد التحقق من رقم المادة ونصها
}
```

عند السؤال عن لائحة يجيب المساعد بـ **إجابة مباشرة** ثم كتلة ذهبية:
📌 القانون / اللائحة التنظيمية (وزارة التربية - الكويت):
> اسم اللائحة — المادة: نص اللائحة

⚠️ **المدخلات الثلاثة الأولى (م 42، م 18، م 12) جاءت من مخطط مولَّد ولم يُتحقق منها.** ما دامت `verified: false` يذكر المساعد اسم اللائحة فقط دون رقم المادة. بعد مطابقتها بالنسخة المعتمدة غيّرها إلى `true`.

## تعديل المعرفة أو السلوك
كل شيء في `assistant/worker.js` داخل المتغير `SYSTEM_PROMPT`:
- **اللوائح**: القسم «المرجع» — عدّل النص أو أضف لوائح جديدة.
- **السلوك**: الأقسام «قواعد الإجابة عن اللوائح» و«قواعد المساعدة الدراسية» و«الأسلوب».

بعد التعديل: الصق الكود في الـ Worker مرة أخرى و **Deploy**. لا حاجة لتعديل `assistant.html`.

## الأسئلة الافتتاحية
في `assistant.html` المتغير `STARTERS` — غيّر النصوص كما تشاء (`rule: true` تلوّن الزر بالذهبي للوائح).

## الحدود والتكلفة
- الفئة المجانية من Gemini API تكفي استخدام مدرسة عادةً؛ راقب الاستهلاك في AI Studio.
- Cloudflare Workers المجانية: 100,000 طلب يومياً.
- `ALLOWED_ORIGINS` تمنع المواقع الأخرى من استخدام مفتاحك عبر الـ Worker.

## استكشاف الأخطاء
| الرسالة | السبب والحل |
|---|---|
| لم يُضبط عنوان الخادم بعد | `API_URL` ما زال بالقيمة الافتراضية |
| Origin not allowed | رابط الموقع غير مطابق لـ `ALLOWED_ORIGINS` (انتبه لـ http/https ولا تضع `/` في النهاية) |
| GEMINI_API_KEY is not set | لم يُضف السر في إعدادات الـ Worker |
| Gemini error 404 / model not found | غيّر قيمة `MODEL` إلى نموذج متاح في حسابك (تجد القائمة في AI Studio) |
| 429 | تجاوزت حصة الطلبات — انتظر أو فعّل الفوترة |
