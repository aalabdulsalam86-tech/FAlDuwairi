# 👩‍🏫 بوابة المعلمين — نظام متابعة الطلاب

```
school.html              ← الصفحة (تسجيل الدخول / التسجيل / إدخال الأسبوع / التحليل / الإدارة)
school/worker.js         ← الخادم على Cloudflare (المصادقة + قاعدة البيانات)
school/schema.sql        ← جداول قاعدة البيانات
school/seed_students.sql ← الشعب الـ22 والطلاب الـ593 (العام 2026/2027)
```

الطلاب والسجلات محفوظة في قاعدة بيانات **Cloudflare D1** خلف تسجيل الدخول، وليست في ملفات الموقع العامة.
لا يُخزَّن الرقم المدني للطلاب — الاسم والشعبة والتسلسل فقط.

---

## ١. إنشاء قاعدة البيانات D1
1. dash.cloudflare.com → **Workers & Pages → D1 SQL Database → Create** — سمّها `falduwairi-school`.
2. افتح القاعدة → تبويب **Console**.
3. الصق محتوى `schema.sql` بالكامل → **Execute**.
4. الصق محتوى `seed_students.sql` بالكامل → **Execute**. (إن رفض الحجم، الصقه على دفعتين عند أي سطر يبدأ بـ `INSERT`.)
5. تحقق: `SELECT COUNT(*) FROM students;` → 593.

## ٢. نشر الـ Worker
1. **Workers & Pages → Create → Create Worker** — سمّه `falduwairi-school` → Deploy.
2. **Edit code** → احذف الموجود → الصق `school/worker.js` → **Deploy**.
3. **Settings → Bindings → Add → D1 database**: Variable name = `DB` (بالضبط)، اختر `falduwairi-school` → Deploy.
4. **Settings → Variables and Secrets → Add**:

| الاسم | النوع | القيمة |
|---|---|---|
| `ADMIN_USER` | Text | `Abdullah208` |
| `ADMIN_PASS` | **Secret** | `Duwairi@2026` (غيّرها كما تشاء) |
| `SESSION_SECRET` | **Secret** | أي نص طويل عشوائي (30 حرفاً فأكثر) — لا تشاركه |
| `ALLOWED_ORIGINS` | Text | `https://aalabdulsalam86-tech.github.io` |

   ثم **Deploy**.
5. انسخ رابط الـ Worker (`https://falduwairi-school.<اسمك>.workers.dev`). فتحه في المتصفح يعرض `{"ok":true,...}`.

## ٣. ربط الصفحة
في `school.html` عدّل السطر:
```js
const API_URL = "https://falduwairi-school.<اسمك>.workers.dev";
```
وارفع الملف إلى GitHub.

## الاستخدام

### المعلم
1. **📝 تسجيل معلم جديد**: الاسم، القسم، بريد وزارة التربية (`t…@moe.edu.kw` فقط)، كلمة مرور، والشعب التي يدرّسها.
2. يختار الشعبة من القائمة الجانبية ويرى أسماء طلابها.
3. **إدخال الأسبوع**: يختار رقم الأسبوع (1–12) ويدخل لكل طالب: الحالة (حاضر/غائب/بعذر/مريض/رحلة)، السلوك /1، الأنشطة /2، العملي /3 → درجة الأسبوع /6 تلقائياً. في الأسبوع 12 يضيف المشروع /4 والاختبار /10 → النهائي /20 يُحسب تلقائياً (متوسط الأسابيع + المشروع + الاختبار) ويمكن تعديله.
   أزرار مساعدة: «الكل حاضر» و«درجة كاملة للحاضرين». ثم **💾 حفظ**.
4. **سجل الفصل**: خريطة حرارية طالب × أسبوع + تصدير CSV بنفس أعمدة `student_progress.csv` لتشغيل دفتر Jupyter عليه.
5. **📊 التحليل** (نفس قواعد الدفتر):
   - مؤشرات: الحضور الفعلي، متوسط الأسبوع، الضعاف (<3)، التراجع/التحسن (±1)، خطر الرسوب.
   - رسم متوسط الشعبة عبر الأسابيع وتوزيع الدرجات.
   - **التنبيه الأسبوعي**: مقارنة بآخر أسبوع حضور (🟢 تحسّن ≥1 · 🔴 تراجع ≥1 · ⚪ مستقر <0.5 · 🟡 يحتاج انتباه · <3 = أقل من 50%)، واتجاه 3 أسابيع (🥇 / ⛔ / ⚪ / 🟡).
   - **تقرير نهاية الفصل**: 🔴 أقل من 10 · 🟡 10–14 · 🟢 14 فأكثر · ⚠ التزام ضعيف (<3).
   - **تفاصيل طالب**: خط زمني، أسابيع الغياب، الاتجاه، والنتيجة المتوقعة /20 (انحدار خطي من نتائج الشعبة كما في الدفتر).
6. **⚙️ تعديل شعبي** لتغيير الشعب لاحقاً.

كل معلم يرى سجلاته هو فقط (المعلمون المختلفون للشعبة نفسها لا يرون بعضهم).
